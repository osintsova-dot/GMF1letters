# GMF1 — генератор отчётов Speak & Smile

Действующая версия: https://osintsova-dot.github.io/GMF1letters/

## Unit 3: отчёт после теста

Выберите Unit 3 в режиме одного ученика или всей группы. Вместо общих оценок 1–5 заполните отдельные наблюдения: понимание и называние частей тела, описание своего и другого персонажа, понимание описания, чтение сочетаний и a-e. Отмечайте только проверенное; пустое значение означает отсутствие данных.

Выберите один следующий шаг. «Предложить поддержку» заполняет только пустые поля рекомендаций; учитель проверяет и редактирует текст. Для уже освоенного умения усложнение задаётся вручную. Внесите балл теста, пример из работы, действия учителя и срок повторной проверки.

Данные хранятся в localStorage на текущем устройстве, по имени педагога и ученика. Черновик наблюдений сохраняется при изменении полей; кнопки сохранения записывают также результаты теста и остальные сведения. Старые записи и остальные юниты сохраняют прежний формат. Баллы 1–5 не преобразуются в наблюдения Unit 3.

«Мои ученики → данные юнита» показывает сохранённый отчёт Unit 3. Отправка по-прежнему проходит через проверку администратора; изменение генератора не отправляет сообщения.

Код нового блока: unit3.js / unit3.css. index.html подключает его, передаёт данные и сохраняет поле u3. В годовой статистике новые наблюдения не превращаются в оценки 1–5.
