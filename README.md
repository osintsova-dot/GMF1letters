# GMF1 — генератор отчётов Speak & Smile

Действующая версия — https://osintsova-dot.github.io/GMF1letters/

Starter и Units 1–9 линии продолжающих используют отдельные наблюдаемые умения и чтение. Всего в карточках 69 пунктов. Темы и фоника сверены с поурочными планами Teaching Hub. Отчёты по юнитам выдаются после теста, по Starter — по наблюдениям на уроках.

Учитель выбирает уровень выполнения каждого проверенного задания, добавляет конкретный пример и один следующий шаг. Кнопка «Предложить поддержку» заполняет пустые поля действий на уроках и дома. Формулировки проверяет учитель. Для освоенного умения усложнение задаётся вручную. Внесите срок и задание повторной проверки.

Черновики, баллы теста и учебная практика сохраняются в localStorage по педагогу, ребёнку и блоку. Они восстанавливаются при смене блока или имени. Кнопки сохранения добавляют запись в «Мои ученики». Годовой отчёт собирает сведения по сохранённым блокам.

Записи Unit 3 прежней версии с полем `u3` и черновики `ss_u3draft_v1_*` читаются автоматически. Прежние общие оценки 1–5 доступны в сохранённых записях. При пересохранении они сохраняются в `legacyScores`. Новые наблюдения лежат в `assessment`, черновики — в `ss_assessment_v2_*`.

Данные карточек находятся в `assessment-data.js`, форма и сборка текста — в `assessment.js`, оформление — в `assessment.css`. Файлы `unit3.js` и `unit3.css` оставлены для ранее закэшированной страницы генератора.

Отправка готовых отчётов проходит через проверку администратора школы.
